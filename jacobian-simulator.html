Jacobian Robot Simulator Web App

TypeWeb AppDateJune 2026

A browser-based 2D kinematics simulator for building and testing arbitrary robot arms. Assemble custom joint chains with rotation and travel limits, then drag the end effector and watch the arm solve in real time.

Key figures
StackReact, TypeScript, HTML5 canvas
SolverDamped least-squares pseudoinverse of the Jacobian
Physics engineNone; custom kinematics

How it solves

The inverse kinematics implementation uses the damped least-squares pseudoinverse of the Jacobian, which keeps the solver stable near singularities. Joint values display alongside a live workspace visualization, which makes the relationship between Cartesian paths and joint trajectories visible rather than abstract.

It is built in React and TypeScript with an HTML5 canvas renderer and a custom kinematics implementation, with no physics engine underneath.

Why build it

Seeing an arm fold through a singularity teaches the concept faster than deriving it. The simulator exists to make Jacobian-based motion something you can build intuition about by playing with it.

Tools and methods

React, TypeScript, HTML5 canvas, Linear algebra
